HƯỚNG DẪN CÀI ĐẶT & TÍCH HỢP SKILL

Hướng dẫn tích hợp cấu hình CLAUDE.md và các kỹ năng mã nguồn mở vào dự án thực tế.

1. Cấu hình CLAUDE.md 
# Quy chuẩn Dự án Lập trình

- Framework: React / Next.js / TypeScript
- Thiết kế: Áp dụng Taste Skill (giao diện thực tế, không dùng gradient tím sáo rỗng)
- Tối ưu Token: Dùng Graphify định vị file trước khi nạp codebase
- Quy tắc: Tự động chạy test và commit Git sau mỗi thay đổi lớn

Đặt file này tại thư mục gốc của repo để Claude Code tự động tuân thủ mọi nguyên tắc dự án.

2. Cấu trúc đóng gói SKILL.md 
---
name: ten-skill
description: Hướng dẫn Claude khi nào nên kích hoạt kỹ năng này
---

# Quy trình Thực hiện:
1. Đọc yêu cầu đầu vào từ người dùng
2. Khảo sát cấu trúc tệp liên quan
3. Thực thi theo các bước chuẩn mực đã định nghĩa

Lưu tại thư mục .claude/skills/<ten-skill>/SKILL.md để mở rộng kỹ năng chuyên ngành cho Agent.
